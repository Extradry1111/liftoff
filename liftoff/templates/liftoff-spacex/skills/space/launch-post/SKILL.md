# Launch post

## Modes

**pre**: about 60 minutes before. Give the time, the stakes and where to watch.
**live**: during the flight, one or two lines per milestone (liftoff, max-Q, staging, catch, splashdown).
**recap**: after. Say what happened, the one number that matters and what's next.

## Template: pre

```
[hook: the stakes in one line, under 110 chars]

[vehicle] lifts off at [time UTC] from [site].

what to watch:
→ [milestone + T+ time]
→ [milestone + T+ time]

stream: [official link]
```

## Template: recap

```
[hook: the result in one line]

→ [confirmed fact]
→ [confirmed fact]
→ [the number: flight #, booster reuse count, launches this year]

next: [next milestone / launch]
```

## Rules

- Use only facts verified in this session. Unconfirmed claims get "unconfirmed:" or don't go in.
- Match the user's voice from memory: casing, emoji use and length. If you don't know it, ask for 2 example posts once.
- The first line is under 110 characters and makes sense without context.
- No em dashes. Use a period, a colon or →.
- Give **2 hook options** and one body, and let the user pick.
- Never post on the user's behalf. Only draft.
