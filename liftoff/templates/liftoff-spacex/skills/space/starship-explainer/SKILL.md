# Starship explainer

## Format

```
[One sentence: what it is / what happened]

What they were testing:
→ [goal 1]
→ [goal 2]

What happened (confirmed):
→ [result]

Still unclear:
→ [only if relevant]

Why it matters: [one or two sentences, linking it to Moon, Mars or cost]
```

## Rules

- **Check live first.** Results and goals come from SpaceX's own mission page and updates. Then add credible reporting and say who it came from.
- **Keep confirmed and unconfirmed apart.** Use the "Still unclear" line instead of guessing.
- **One analogy, max.** Only use it if it actually helps ("the tower catches the booster like chopsticks catching a falling pencil").
- **Define jargon once** the first time you use it, in parentheses.
- If the user says "more", go deeper: the timeline by T+ seconds, comparison with the previous flight, and what changed on the hardware.
