# Rewards log

Rewards are decided every two weeks and paid in USD to X Money. They're discretionary and the formula isn't public, so treat this as a lab notebook.

## Each period, ask for

- The period dates
- The payout amount, from X Money
- For each template: any usage the user can see, and what changed (edits, new routine, posts)

## Keep this table in memory

| Period | Template | Payout | Changed this period | Posts |
|---|---|---|---|---|

## Then answer

1. **What moved?** Only claim a cause when the timing clearly lines up. Otherwise write "unclear".
2. **One experiment per template** for the next period: add a daily routine, shorten the first message, post a real output, cut a skill.
3. **Kill or keep.** If a template is flat for 3 periods even after changes, retire it and BUILD a new one.

Never invent numbers. Keep payout figures out of drafted posts unless the user asks for them.
